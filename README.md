# L_Shop

Интернет-магазин в формате SPA.

Фронтенд написан на `TypeScript`, backend на `Express + TypeScript`.

## Структура проекта

- `client` - клиентская часть
- `Back` - основной backend, который используется сейчас
- `Back/DataBase` - хранение данных в `json`
- `server` - старая версия backend, для текущего запуска не используется

## Что реализовано

- регистрация и авторизация
- `HttpOnly` cookie-сессия на 10 минут
- каталог товаров
- поиск, сортировка и фильтрация товаров
- корзина
- изменение количества товаров в корзине
- удаление товаров из корзины
- оформление доставки
- изменение статуса доставки
- хранение данных в `json` файлах
- SPA-маршруты: `/catalog`, `/auth`, `/basket`, `/delivery`

## Установка

Сначала нужно установить зависимости для клиента и backend.

```bash
cd client
npm install
cd ../Back
npm install
```

## Запуск

Запускать проект нужно из папки `Back`.

```bash
cd Back
npm start
```

После запуска приложение будет доступно по адресу:

```text
http://localhost:3000
```

`Back` сам собирает клиент и потом запускает сервер.

## Полезные команды

Проверка типов:

```bash
cd Back
npm run check
```

Сборка проекта:

```bash
cd Back
npm run build
```

Запуск в режиме разработки:

```bash
cd Back
npm run dev
```
