# L_Shop

SPA интернет-магазин с клиентом на TypeScript и backend на Express + TypeScript.

## Структура

- `client` - фронтенд SPA
- `server` - backend API и файловое хранилище

## Установка

```bash
cd server
npm install
cd ../client
npm install
```

## Запуск

```bash
cd server
npm start
```

Приложение будет доступно по адресу `http://localhost:3000`.

## Что реализовано

- регистрация и авторизация
- `HttpOnly` cookie-сессия на 10 минут
- каталог товаров с поиском, сортировкой и фильтрацией
- добавление товара в корзину с выбором количества
- изменение количества и удаление товаров из корзины
- оформление доставки и очистка корзины после успешного заказа
- хранение данных в `json` файлах
- SPA-маршруты: `/catalog`, `/auth`, `/basket`, `/delivery`
